# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
building the ui imperatively requires you to create whats the next step or build how the ui would look like for current data manually. while declaratively only requires you only to describe how it should look like. 

2. Why must a component name start with a capital letter?
to differentiate html built in tag and our component

3. What does a fragment <>...</> do, and why not just use a <div>?
it returns multiple elements from the component without adding extra element to the html. div will add unnecessary wrapper that can clutter the page

4. Name one benefit of splitting the UI into small components.
You can reuse the components in other places
